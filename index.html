    使用说明 / 隐私说明

    怎么用

    1. 不需要任何配置：粘贴文章，点「开始评分」，页面会自动联网用公共免费接口打分（默认引擎「免 Key 自动」）。
    2. 文章建议 1 万字符以内，超长会被拦截；空内容、网络异常、限流都会有明确提示。
    3. 结果可一键复制为 Markdown 或纯文本；不满意可点「重新评分」重跑。
    4. 想要更稳定的效果，可展开「高级设置」切换到「自定义 API」（填自己的 Base URL / Key / 模型）或「本地规则」。

    三种引擎

    • 免 Key 自动（默认）：调用公共免费接口 Pollinations（OpenAI 兼容协议），无需注册。匿名额度约为同一 IP 每 45 秒 1 次，被限流时页面会自动排队重试，最多 3 次。
    • 自定义 API：填自己的 Base URL / Key / 模型，可对接 DeepSeek、通义千问、OpenAI、本地 Ollama 等，速度与稳定性取决于你自己的服务。
    • 本地规则：完全离线，只用句式与关键词特征粗略估计 AI 重合度，准确性与原创度仅给提示、不打分。

    评分口径

    • 准确性：数据 / 人名 / 公司 / 时间 / 政策是否可信，有无夸大与标题党式误导，逻辑是否自洽、结论有无依据。
    • 原创度：是否与网络常见模板高度重合，信息密度是否足够，观点与案例是否新鲜，是否只是换了词的重排。
    • AI 重合度：数值越高越像 AI 生成。典型痕迹包括密集三连排比、对称套句、「值得注意的是 / 换句话说」类过渡、总分总模板、空洞金句、段落长度高度均匀、缺乏具体细节与个人化语气。
    • 今日头条更看重时效热点、具名公司与硬数据、可被反驳的明确判断；对标题党和情绪化容忍度较高，但反感泛泛而谈的行业观察。

    颜色约定

    绿 = 较好，橙 = 一般，红 = 需改进。AI 重合度做了方向反转：分数越低越绿（越像真人写作），越高越红。

    隐私说明

    • 本页面没有自有后端、无埋点、无统计，文章只会在浏览器与评分接口之间传输。
    • 「免 Key 自动」模式会把文章正文发送给第三方公共免费服务 Pollinations（text.pollinations.ai）以完成打分，请勿用它处理敏感或未公开内容；介意的请改用「自定义 API」或「本地规则」。
    • 「自定义 API」模式只发送到你自己填写的 API 地址；「本地规则」模式全程离线，不发出任何网络请求。
    • API Key 与配置仅保存在当前浏览器的 localStorage，不会外发；可随时点「清除密钥」删除。

    常见问题

    • 提示「免费接口排队中」：公共接口对匿名访问限流（约每 45 秒 1 次），页面会自动等待并重试；急着用就切到「自定义 API」。
    • 返回被截断 / 不是 JSON：免费模型输出长度有限，长评分可能截断。页面会自动尝试修复截断的 JSON（救回已返回的维度，缺失的显示「未评分」）；仍失败请点「重试」或换自定义 API。
    • 免 Key 模式失败：公共免费服务可能临时不可用，可稍后重试，或点「改用本地规则」立即拿到粗略结果。
    • 提示网络失败 / CORS：部分服务未开放浏览器跨域访问。可换用支持 CORS 的服务商；本地 Ollama 需设置 OLLAMA_ORIGINS=* 后重启。
    • 401 / 403：Key 错误或没有该模型权限。404：Base URL 少了 /v1 或多了路径。
    • 部署到 GitHub Pages：把本文件命名为 index.html 推到仓库，在 Settings → Pages 选择对应分支即可。
